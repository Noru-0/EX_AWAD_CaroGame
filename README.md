# React Tic-Tac-Toe Game

A modern, fully-featured Tic-Tac-Toe game built with React and Vite.

🎮 **[Play the Game Online](https://ex-awad-carogame.onrender.com)** 🎮

## Features

- ✨ **Interactive Gameplay**: Multiple board sizes (3x3, 5x5, 7x7, 9x9)
- 🏆 **Winner Detection**: Highlights winning squares with animations
- 📜 **Game History**: Track all moves with location display (row, col)
- 🎯 **Current Move Indicator**: Shows "You are at move #..." for current position
- 🔄 **Move Sorting**: Toggle between ascending/descending move order
- 🎨 **Beautiful UI**: Modern glassmorphism design with animations
- � **Responsive Design**: Optimized for all screen sizes
- 🎮 **Full-Screen Experience**: No scrollbars, perfectly fits viewport

## Getting Started

### Prerequisites
- Node.js (version 18 or higher)

### Installation
1. Clone the repository
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```

## How to Play

1. Select your preferred board size from the dropdown (3x3, 5x5, 7x7, or 9x9)
2. Players take turns placing X's and O's
3. Get a full row, column, or diagonal to win
4. Use the move history to jump to any previous game state
5. Sort moves in ascending or descending order

## Technologies Used

- **React 18** - UI framework
- **Vite** - Build tool
- **CSS3** - Modern styling with animations
- **JavaScript ES6+** - Game logic
